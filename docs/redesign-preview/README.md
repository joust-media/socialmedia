# Redesign preview gallery

Screenshot walkthrough of the portal redesign at commit `3a87377`, rendered against sample data. Nothing here is deployed; it is a static capture for review.

## How to view

- **Paged version:** open [`gallery.pdf`](gallery.pdf) on GitHub. It is a 15-page A4 document and GitHub's PDF viewer pages through it.
- **Interactive version (dark mode, lightbox):** open [`gallery.html`](gallery.html) in a browser. Once this branch is deployed to staging it is also available at `/socialmedia-staging/docs/redesign-preview/gallery.html`.

## Note

This folder is a review aid only. Delete it before merging `claude/portal-redesign` into `main`.
